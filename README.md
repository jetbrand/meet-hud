# Google Meet 自己監視

Google Meet で、**自分のマイク・カメラ・送信回線が Meet サーバーへちゃんと届いているか**に気づく Chrome 拡張です。

相手の受信品質は見えません。相手の Wi-Fi が悪い場合はどうしようもありません。見ているのは「自分 → Meet サーバー」です。

## できること

画面上部中央に小さな HUD が出ます。クリックで詳細を開閉します。

| 表示 | 意味 |
| --- | --- |
| OK | Meet サーバーへの送信は問題なさそう |
| NOISE | マイク ON のまま周囲の音を拾っている |
| 送信NG | カメラ映像の劣化、または遅延・パケットロス |

マイク OFF のときのノイズや、カメラ OFF・無音で送信量が少ないことは、回線不良扱いしません。

## 入れ方

Chrome ウェブストアには出していません。zip を読み込みます。

1. [Releases](https://github.com/jetbrand/meet-hud/releases) から最新の `meet-noise-alert-v*.zip` をダウンロードする
2. 解凍する（中に `manifest.json` があること）
3. Chrome で `chrome://extensions` を開く
4. 右上のデベロッパーモードをオンにする
5. 「パッケージ化されていない拡張機能を読み込む」で解凍したフォルダを選ぶ
6. Meet のタブを一度閉じて開き直す（通信フックはタブ開始時に入ります）

開発中なら、このリポジトリを clone して同じ手順でフォルダを読み込んでも構いません。

## 使い方

1. Meet に入る
2. 画面をクリックする（マイク監視の開始。ブラウザの自動再生制限のため）
3. 左から MIC / CAM / NET のドットを見る
4. 詳細が必要なら HUD をクリックして開く

マイク許可を求められたら許可してください。音声はローカルで音量を見るだけです。外部には送りません。

## 配布（メンテする人向け）

`v*` タグを push すると GitHub Actions が zip を作って Release に載せます。zip 内の version はタグから埋め込みます。

```bash
git tag v1.2
git push origin v1.2
```

既存タグを付け直すと、古いコミットの workflow が動くことがあります。付け直すならタグを消してから、直した `main` の先端に打ち直してください。

## 構成

| ファイル | 役割 |
| --- | --- |
| `page-hook.js` | Meet の WebRTC 送信統計を取る（ページと同じ MAIN world） |
| `meet-devices.js` | Meet のマイク／カメラ ON・OFF |
| `model.js` | 判定 |
| `hud.js` / `hud.css` | 表示 |
| `icons/` | 拡張アイコン |
| `content.js` | 起動と 1 本の更新ループ |
| `protocol.js` | 2 つの world のあいだのメッセージ契約 |
